# ChangeLog

## [2.0.0] - 2026-10-18
 - STM32duino-only port of the DMD_STM32 1.2.18 SPWM drivers (STM32F1 / STM32F4).
 - Removed: classic LED driver classes (DMD_RGB, FM6126a, monochrome SPI/parallel),
   Adafruit_GFX dependency, GFX fonts, marquee API, libmaple and RP2040 support.
 - New: RGB565 framebuffer with gamma-corrected 12..14-bit greyscale output,
   setPixel()/primitives/DMD bitmap fonts, working setBrightness().
 - Timers/DMA via LL drivers; row interrupt installed in a RAM vector table.
 - Register Config Finder rewritten as examples/spwm_register_finder using
   setConfigRegisters()/dmdApplyRegProfile().
